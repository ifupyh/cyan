用了一个月 DeepSeek Harness（下面简称 DSH），我最大的感受是：**决定它好不好用的，往往不是模型，而是插件。**

刚装好的 DSH 是个干净的对话框，能聊、能读文件、能跑命令，但也仅此而已。装上插件之后，它才开始有"记忆"、会"算账"、能打开 Excel 改公式、能隔着微信接任务，甚至能直接操作你的 Windows 桌面。

这篇把我实际留下、每天都在用的 10 个插件整理成一份清单，附安装方法和踩过的坑。不用全装，按需取用。

## 0. 装插件之前：先把 DSH 跑起来

如果你还没装 DSH，这一步很快：

1. **下载安装**。官网是 <https://www.deepseek.com/harness/>，安装路径建议**不要放 C 盘**，后面模型缓存、会话记录、插件依赖都会占空间。
2. **登录或注册**，然后看一眼余额。点右下角头像 →「设置」，就能看到账户余额。新用户一般会赠送 5 元，够玩很久；如果没有，充一点保证有余额即可。

![右下角头像菜单，设置入口在这里](/assets/images/posts/dsh-plugins/dsh-settings.webp)

3. **添加工作区**。点左边栏「更多」旁边的文件夹图标，或者直接点对话框里的「选择工作区」，挑一个干净的文件夹加进来。工作区就是它默认读写文件的范围，建议一个项目一个文件夹。

![添加工作区：左侧文件夹图标，或对话框里的「选择工作区」](/assets/images/posts/dsh-plugins/dsh-workspace.webp)

4. **选择模型**，然后就可以开始对话了。模型下拉框里能看到当前账号可用的模型，日常用 Flash 就够快，复杂任务再切 Pro。

![模型选择：DeepSeek-V4.1-Flash 日常够用，重活切 V4-Pro](/assets/images/posts/dsh-plugins/dsh-model.webp)

5. **打个招呼**。它会先报一遍当前的工作目录，再告诉你它擅长什么，顺便确认文件和命令都通：

![第一次对话：它会先报出当前工作目录，再告诉你它能做什么](/assets/images/posts/dsh-plugins/dsh-first-chat.webp)

## 1. 插件怎么装：两条路，都很快

DSH 的插件本质上是 npm 包（bundle），安装方式有两种，外加一条命令行路线。

### 方式一：直接跟它说（推荐新手）

在对话框里输入：

```text
帮我安装 dsh-market
```

它会先检查是否已安装、是什么版本，然后自动卸载旧版、安装新版。期间可能弹窗询问是否允许访问网络，**确认来源可信后再同意**。整个过程两分多钟，装完会给你一张"做了什么"的清单。

![对话式安装：它会先查版本，再卸载旧版、安装新版](/assets/images/posts/dsh-plugins/dsh-install-chat.webp)

### 方式二：插件页手动添加

打开左侧「插件」→ 右上角「+ 添加插件」→ 输入包名、GitHub 仓库地址或本地目录 → 点「安装」。

![插件页添加插件：输入包名，按需切换安装源，然后点安装](/assets/images/posts/dsh-plugins/dsh-plugin-page.webp)

两个细节值得注意：

- 输入框下方可以选「安装源」，国内网络建议直接选**中国大陆镜像**，否则拉包可能很慢。
- 弹窗里会明确警告：**插件以你的权限在本机运行**，来源不明的插件可能损坏 DSH 或读取你的数据。这不是客套话，装之前扫一眼作者和仓库。

### 方式三：命令行（Web 版进阶）

如果你用的是 Web 版 profile，也可以直接命令行安装：

```bash
dsh plugin --profile web add dsh-cost-meter
```

注意：**Electron 桌面版独占 `desktop` profile，CLI 对它的命令会被拒绝**。桌面用户老老实实用前两种方式就好，让 DSH 自己装是最省事的。

### 三个通用提醒

1. **装完重启 DSH**。大部分插件需要重启后才会在界面上出现入口。
2. **别一次装太多**。插件会改工具面、加提示词、注册后台服务，装十几个很容易互相打架。
3. **权限要看清**。插件能读写文件、跑命令、访问网络、读取凭据；装之前先看一眼仓库和作者，来路不明的包，功能再诱人也不装。

## 2. 基础设施：这四个先装

### 01 dsh-market：先把"应用商店"装上

这是清单里唯一"为了装别的插件而装"的插件，但它是真的省事。

装好之后左侧栏会多出「插件市场」，里面有一万三千多个社区插件，支持搜索、分类、一键安装和更新，还有一键换主题。你不需要再去 npm 上翻包名，也不用记 GitHub 地址。

**适合谁**：所有人，尤其是刚接触 DSH、不知道该装什么的新手。

**小提示**：市场里的插件质量参差不齐，优先选下载量高、最近有更新、仓库有 README 的；一个插件如果需要跑命令、读凭据、连网络，先想清楚它到底要干什么。

### 02 billion-context：把一个会话用到天荒地老

这是 DSH 生态里最"值钱"的插件，没有之一。

所有大模型都有上下文窗口。聊得越久，历史越长，token 越贵，超过窗口还会崩。`billion-context` 的做法不是硬截断，而是**让模型自己决定压缩什么**：把早期的对话折叠成分层摘要，需要细节时再解压取回。

它给对话注入了四个工具：

- `compress`：把一段消息折叠成摘要；
- `decompress`：需要精确细节时恢复某段内容；
- `search_context`：在摘要和可见消息里做关键词检索；
- `acp_status`：查看上下文用量，以及哪些区间还能压。

官方口径是**省 5 倍 token、100K 上下文就够用、单会话可以跑数月**。近 30 天下载量约 380 万次，属于"闭眼装"的级别。

两个使用心得：

- **别频繁开新会话**。新会话意味着全新的缓存前缀，第一轮必然是缓存未命中，反而更贵。长任务就待在一个会话里，让它自己压。
- **压缩是有损的**。摘要会丢掉细节，需要原话、原始报错时，明确让它 `decompress` 或 `search_context`，不要凭印象继续。

### 03 dsh-cost-meter：钱到底花在哪，一眼看到

DSH 自带余额显示，但想知道"这一轮花了多少、今天花了多少、哪个模型最烧钱"，就得靠它。

`dsh-cost-meter` 会在对话界面里给出：

- 本会话成本、当日总花费、历史记录；
- 内置 170+ 模型的价格目录，自动匹配你正在用的模型；
- 主流 Coding Plan 的订阅额度查询（十几家厂商）；
- 峰谷时段提示：工作日 9:00–12:00、14:00–18:00 是峰时，周末和法定节假日全天谷价，切换前还会弹窗或发系统通知。

举个真实的例子：截图里这个会话跑了 120 万 token，缓存命中 95%，账单是 **0.1497 元**。看到这个数字，你才会真正理解"缓存命中"和"上下文压缩"为什么值钱。

**使用建议**：把批量整理、长文写作这类不急的活，挪到谷时跑；峰时只做交互式的小任务。

### 04 cc-safety-net：给"能动手"的 AI 上保险

AI 能跑命令是好事，也是风险。`cc-safety-net` 做的事很纯粹：**在命令真正执行之前，解析它到底要干什么**，然后拦下两类操作：

- 破坏性命令：`rm -rf`、`git reset --hard`、危险的磁盘操作；
- 敏感文件访问：SSH 私钥、`.env`、各类凭据文件。

它不是沙箱，不负责限制进程和网络，但它能挡住最常见的"手滑"。而且它解析的是命令的真实语义，包装一层、调换参数顺序都藏不住；就算配置文件坏了，也只会放行，不会误拦。

**适合谁**：所有让 AI 碰真实项目目录的人，尤其是新手。

## 3. 提效：同样的活，少烧一半 token

### 05 dsh-ops：给工具面做减法

DSH 默认给模型塞了不少工具，每个工具的说明都要占系统提示词。`dsh-ops` 的思路是：**换一套更紧凑的工具，把不必要的藏起来**。

装好之后，文件读写、命令执行会走它的 `ops_` 系列工具（这篇文章的素材整理，我用的就是它的 `ops_bash`、`ops_grep`）。在 Windows 上，它可以用 `ops_bash` 替代 PowerShell，命令更短、返回更紧凑、报错更清晰，模型不容易在报错循环里打转。

它还有 18 个 PTC 模式的 API、可选的批量修改工具，以及一个"按需加载"的机制：PDF、Word 读取这类不常用能力，用到时才加载，不占日常上下文。

**适合谁**：每天都用、对 token 账单敏感的重度用户。新手可以先跳过，等觉得"怎么每轮都在烧钱"时再装。

### 06 dsh-mnemon：让它记住你

默认情况下，DSH 每个新会话都从零开始。你得反复解释："我是做前端的""这个项目用 pnpm""不要给我写 Java"。

`dsh-mnemon` 给 DSH 加了一套**分层记忆**：

- 偏好和当前事实放在工作记忆里，每轮都在；
- 项目文档、长期资料放进「记忆空间」，需要时才检索；
- 每条回复下面有一条"本轮记忆"栏，告诉你这一轮读了什么、写了什么，点开就能改；
- 遇到值得记的事，点一下回复下方的小脑图标，它会交给一个子智能体去重、提炼，再写进合适的记忆空间。

它还把「技能」管了起来：可以复盘真实对话、起草更好的 `SKILL.md`、先回测再采用。数据默认存在本地，也可以接八种第三方存储。

**适合谁**：长期做同一个项目、或者同时维护好几个项目的人。

### 07 技能中心：把 skill 管起来

装了几个技能包之后，很容易忘记自己到底有哪些 skill、哪些在生效。

「技能中心」按来源把所有技能分级展示：系统内置、项目 `.dsh/skills`、用户 `~/.dsh/skills`、自定义目录、运行时注册。每一行都能看到描述、触发条件，并且可以：

- 一键启用 / 禁用模型调用（改的是 `SKILL.md` 的 frontmatter，热刷新）；
- 新建技能、复制现成技能当模板；
- 删除（进 `.trash` 回收站，可恢复）。

**适合谁**：装了技能包、或者自己写 skill 的人。它不产生新能力，但能让你少犯"技能装了却没生效"的错。

## 4. 长手：从"说"到"做"

### 08 dsh-univer-office：真·Office

大多数 AI 办公方案的本质是"生成一段 CSV/Markdown 让你自己粘"。`dsh-univer-office` 不一样：它把一整套 Univer 运行时塞进了 DSH，电子表格、文档、幻灯片、多维表格、画布都在里面。

你可以直接说：

```text
把这个 CSV 做成带条件格式和图表的销售报表，导出 xlsx
```

它会真的打开一个表格窗口，边做边给你看；改完不是直接覆盖，而是进入一个隔离的工作树（worktree），你可以预览、合并、或者丢弃。确认没问题，再导出成 `.xlsx` / `.docx` / `.pptx`。

**适合谁**：要交周报、报价单、答辩 PPT、数据看板的人。**提示**：需求里说清"给谁看、什么风格、多少页/多少行"，比说"做个好看的"有效十倍。

### 09 dsh-windows-mcp：把电脑交给它

这个插件通过 DSH 内置的 MCP 桥，把 Windows 桌面自动化接进来。装好之后，模型多了这些工具：

- `Screenshot`：截屏，图片直接进对话；
- `Snapshot`：抓无障碍树，纯文本、不花图片 token；
- `Click` / `Move` / `Scroll` / `Type` / `Shortcut`：鼠标键盘；
- `Clipboard` / `Process` / `Registry`：剪贴板、进程、注册表。

典型用法：让它打开某个网页、填一张固定表单、把一堆文件按规则重命名、盯着某个窗口等结果。

**注意三件事**：

1. 需要本机有 [`uv`](https://docs.astral.sh/uv/)，装完插件后到「设置 → 桌面控制」里点"下载并安装"依赖，再重启 DSH；
2. 输入框旁边有一颗「AI 控制电脑」的胶囊，**默认是关闭的**，而且授权只对当前会话有效——换会话、重启都要重新点亮；
3. 想让它"看见"截图，模型本身要支持图片输入。

### 10 dsh-im：在微信里给它派活

`dsh-im` 把 DSH 接到 IM 上：微信、企业微信、飞书、钉钉、QQ、Telegram、WhatsApp、Slack、Discord、Matrix 都支持，扫码或填机器人凭据即可。

装好之后，左侧会多出「IM 机器人」。你在手机上发一句话，它就在电脑上接着干；跑长任务时尤其有用——通勤路上派活，回家看结果。

**注意**：机器人能读到对应会话里的内容，也能以你的身份回复，权限范围要提前想清楚；只加自己可控的群和账号。

## 彩蛋：小鲸鱼挂件

严格来说它不提升生产力，但它是很多人装 DSH 后第一个舍不得删的插件。

右下角一只小鲸鱼，显示 API 余额、今日已用、每轮对话消耗，还能拖拽吸附、点击刷新、自定义气泡内容（文本、余额、今日、峰谷、随机语句、图片都行）。忙碌的时候它安安静静待着，余额变少的时候数字会滚动提醒你。

**重点**：不需要任何 token，装完就能用。

## 三套搭配方案

不想一次装十个，可以按场景来：

**轻量省钱版（推荐所有人）**

```text
dshmarket + billion-context + dsh-cost-meter
```

先把市场、上下文和账单管住，这三件套能解决 80% 的"用不起、用不久"问题。

**重度干活版**

```text
轻量版 + dsh-ops + dsh-mnemon + dsh-univer-office
```

工具面更省、记忆更久、还能直接产出 Office 文件，适合把它当主力工作台的人。

**极客自动化版**

```text
重度版 + cc-safety-net + dsh-windows-mcp + dsh-im
```

能操作桌面、能被手机遥控，同时有一道安全网兜底。装这套之前，先把权限和隐私边界想清楚。

## 六个坑，提前说

1. **装完不重启，等于没装。** 尤其是带界面的插件，重启后才会有入口。
2. **来源不明的插件别装。** 插件以你的权限运行，能读文件、发网络请求、拿凭据。市场里的警告不是摆设。
3. **插件会互相打架。** 两个都改工具面的插件、两个都做压缩的插件，同时装容易出怪问题。出问题先禁用最近装的那个。
4. **桌面控制默认关闭，且按会话授权。** 这是保护机制，不是 bug。别为了省事去改全局默认。
5. **新会话不一定更省钱。** 每次新会话都是新的缓存前缀，第一轮全价。长任务尽量待在一个会话里。
6. **别把 API Key 贴进对话。** 凭据放「设置」里，插件需要时会自己读；贴进聊天记录，它就永远留在历史里了。

## 最后

DSH 的插件生态现在有一万三千多个包，热闹归热闹，真正值得长期留在机器上的其实不多。上面这 10 个，是我用了一个月、删删减减之后留下来的组合：**市场负责发现，压缩和计费负责可持续，ops 和记忆负责效率，Office 和桌面控制负责落地，安全网负责兜底。**

如果你是刚装好 DSH 的新手，建议顺序是：先装 `dshmarket`，再从市场里装 `billion-context` 和 `dsh-cost-meter`，用一周，确认顺手了，再往下加。

插件是工具，不是收藏品。装得少一点，用得深一点，比什么都强。
