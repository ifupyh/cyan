## 参考答案

1. **DNS 解析**：浏览器查本地缓存 → 系统缓存 → DNS 服务器，把域名解析成 IP 地址
2. **TCP 三次握手**：和服务器建立 TCP 连接
3. **TLS 握手**（如果是 HTTPS）：协商加密套件、交换证书
4. **发送 HTTP 请求**：浏览器发 GET 请求
5. **服务器处理并返回响应**：返回 HTML 等资源
6. **浏览器渲染**：解析 HTML/CSS 构建 DOM 树和渲染树，加载 JS 执行，最终绘制页面
7. **TCP 四次挥手**：连接关闭（或保持长连接复用）
