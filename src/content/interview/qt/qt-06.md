## 参考答案

**结论：** 信号槽是 Qt 的**对象间通信机制**：信号（signal）在事件发生时发出，槽（slot）是响应信号的函数，用 `connect` 关联。

```cpp
// 声明
signals:    void valueChanged(int);
public slots: void onValueChanged(int);
// 连接
connect(sender, &Sender::valueChanged, receiver, &Receiver::onValueChanged);
// 发射
emit valueChanged(10);
```

**特点**：松耦合（发送方不关心谁接收）、一个信号可连多个槽、支持跨线程（队列连接）。
