## 参考答案

| 模块 | 作用 |
|------|------|
| core | 基本数据结构（Mat、Point、Size）、矩阵运算 |
| imgproc | 图像处理：滤波、几何变换、形态学、边缘检测、轮廓 |
| imgcodecs | 图像读写（imread/imwrite） |
| videoio | 摄像头/视频文件读写 |
| highgui | 窗口显示、鼠标键盘事件 |
| video | 视频分析：光流、背景减除、跟踪 |
| dnn | 深度学习模型加载与推理 |
| calib3d | 相机标定、立体视觉 |
