## 参考答案

优化多客户端并发连接的核心是**IO 多路复用 + 线程池**。

演进过程：

1. **多进程模型**：每连接 fork 一个进程，简单但开销大
2. **多线程模型**：每连接一个线程，比进程轻量但线程数有上限
3. **IO 多路复用**：用 `select` / `poll` / **`epoll`** 一个线程监控多个连接
4. **Reactor 模型**：主线程用 epoll 监听事件，事件就绪后分发给**工作线程池**处理

实际高并发服务端主流方案是 **epoll + 非阻塞 IO + 线程池（Reactor）**，像 Nginx 就是这个模型
