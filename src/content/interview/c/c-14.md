## 参考答案

```c
int a;              // 一个 int 变量
int *a;             // 指向 int 的指针
int **a;            // 指向「int 指针」的指针
int a[10];          // 含 10 个 int 的数组
int *a[10];         // 指针数组：10 个元素，每个是 int*
int (*a)[10];       // 数组指针：指向「含 10 个 int 的数组」的指针
int (*a)(int);      // 函数指针：指向「int 参数返回 int」的函数
int (*a[10])(int);  // 函数指针数组：10 个元素，每个是指向上述函数的指针
```

**记忆法：** 从变量名向外读，先结合 `[]`（数组）或 `()`（函数），再结合 `*`（指针）。例如 `int *a[10]`：a 先和 `[10]` 结合是数组，元素是 `int*`。
