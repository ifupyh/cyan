## 参考答案

**结论：** `argc` 是命令行参数个数（含程序名），`argv` 是指针数组，每个元素指向一个参数串。

- `argc` 至少为 1，因为程序自身名字也算一个参数。
- `argv[0]` = 程序名，`argv[1]` = 第 1 个参数，`argv[argc-1]` = 最后一个参数。
- **标准保证 `argv[argc] == NULL`**（这是遍历参数的哨兵）。

```
./program arg1 arg2 arg3
// argc = 4
// argv[0]="./program"  argv[1]="arg1"  argv[2]="arg2"  argv[3]="arg3"  argv[4]=NULL
```
