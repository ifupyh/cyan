## 参考答案

**结论：** extern 声明一个「在其他编译单元定义」的变量或函数，告诉编译器只声明不分配，由链接器去其他目标文件找定义。

```c
// a.c
int g = 10;          // 定义（唯一）
// b.c
extern int g;        // 声明，引用 a.c 的定义
```

**加分点：** `extern "C"`（C++）告诉编译器按 C 的方式处理符号名（不做名字修饰），用于 C/C++ 混合编程；`extern int x = 1;` 是定义而非声明。
