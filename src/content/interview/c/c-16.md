## 参考答案

**结论：** 结构体各成员**独立存储**，共用体各成员**共享同一块内存**。

- 结构体：成员各占各的空间，可同时访问；大小 ≈ 各成员之和（**受内存对齐影响，可能更大**）。
- 共用体：所有成员共用同一地址，同一时刻只能有效使用一个成员；大小 = 最大成员的大小（也对齐）。

```c
struct S { int x; float y; };  // sizeof = 8（4 + 4，正好对齐）
union  U { int a; float b; };  // sizeof = 4（取最大）
```

**加分点：** 共用体常用于：节省内存、类型转换（读取同一字节的不同解释）、大小端判断。
