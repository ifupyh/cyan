## 参考答案

**结论：** 「指针函数」是**返回指针的函数**，「函数指针」是**指向函数的指针**。

```c
int *func(int a);        // 指针函数：返回 int*
int (*p)(int, int);      // 函数指针：p 指向返回 int、参数两个 int 的函数
p = add;                 // p 指向函数 add
int r = p(3, 4);         // 通过指针调用
```

**加分点：** 函数指针三大用途——回调函数、函数指针数组（如实现跳转表/状态机）、作为返回值。`typedef int (*FuncPtr)(int,int);` 能让声明清爽很多。
