## 参考答案

| 类型 | 字节 |
|------|------|
| char | 1 |
| short | 2 |
| int | 4 |
| long | 4（32 位）/ 8（64 位 Linux） |
| long long | 8 |
| float | 4 |
| double | 8 |
| 任意指针 | 4（32 位）/ 8（64 位） |

**加分点：** `sizeof` 的结果依赖平台和编译器，面试要先说明前提（32/64 位、LP64/LLP64）。`char` 是否带符号由实现决定，需用 `signed char`/`unsigned char` 显式指定。
