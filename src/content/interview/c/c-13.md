## 参考答案

**结论：** sizeof 是**编译期运算符**求内存占用，strlen 是**运行期函数**求字符串长度。

| 维度 | sizeof | strlen |
|------|--------|--------|
| 本质 | 运算符（不是函数） | string.h 库函数 |
| 求值时机 | 编译期 | 运行期 |
| 对象 | 任何类型 / 变量 / 数组 | 仅 `\0` 结尾的字符串 |
| 结果 | 占内存字节数（含 `\0`、含填充） | 字符个数（不含 `\0`） |

```c
char str[] = "Hello";
sizeof(str);  // 6：含末尾 '\0'
strlen(str);  // 5
```

**加分点：** 数组作为 sizeof 参数时**不退化**为指针；传给函数则退化为指针，所以函数里 `sizeof(参数数组)` 得到的是指针大小。
