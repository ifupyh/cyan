## 参考答案

**结论：** 抓住「申请要检查、使用要防越界、释放要防漏防重复」三件事。

1. **申请**：检查返回值（malloc 返回 NULL 即失败）；精确计算字节数（`n * sizeof(T)`）。
2. **使用**：不越界访问；先初始化再读（malloc 内容不确定）。
3. **释放**：所有返回路径都要 free/delete；释放后把指针置 NULL 防重复释放/野指针。
4. **多线程**：共享堆内存的访问要加锁。
