## 参考答案

**结论：** 动态内存分配是**运行期**按需申请内存，生命周期由程序员控制。

```c
int *p = (int*)malloc(100 * sizeof(int));  // C 中通常省略强转，C++ 必须强转
// ...使用 p[0..99]
free(p);       // 释放
p = NULL;      // 防野指针
```

- `free` 只能释放由 malloc/calloc/realloc 返回的指针，且只能释放一次。
- 释放后指针内容不变，但已不可解引用，应置 NULL。

**纠正原稿：** C 中 `malloc` 返回 `void*` 可隐式转为任意指针**不需要强转**（强转反而可能掩盖漏 include 的错误）；C++ 才必须强转。
