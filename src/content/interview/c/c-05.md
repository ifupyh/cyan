## 参考答案

**结论：** const 是编译期参与的「只读变量」，#define 是预处理期的「纯文本替换」。

| 维度 | const | #define |
|------|-------|---------|
| 处理阶段 | 编译期 | 预处理期（编译前） |
| 类型 | 有类型，做类型检查 | 无类型，纯替换，无检查 |
| 作用域 | 遵循作用域规则 | 从定义处到文件尾或 #undef |
| 调试 | 进入符号表，可调试 | 不产生符号，难以调试 |
| 内存 | 通常占内存（可被取址） | 不占内存 |

```c
#define MAX(a,b) ((a)>(b)?(a):(b))   // 需处处加括号，否则有优先级/副作用坑
const int MAX_SIZE = 100;            // 类型安全
```

**加分点：** 宏参数有副作用：`MAX(a++, b)` 会把 `a` 加两次。优先用 const / constexpr / inline 替代函数式宏。
