## 参考答案

**结论：** static 有三类用法，含义各不相同。

1. **修饰局部变量（函数内）**：生命周期延长到程序结束，但作用域仍限于该函数，只初始化一次。
2. **修饰全局变量 / 函数（文件作用域）**：改变链接属性为**内部链接**，符号只在本 `.c` 文件可见，用于隐藏实现、避免命名冲突。
3. **修饰类成员（C++）**：静态成员属于类本身而非对象，所有对象共享一份，需在类外定义。

```c
void counter() {
    static int n = 0;   // 只初始化一次，此后每次调用保留上次值
    printf("%d\n", ++n);
}
```

**加分点：** 函数内 static 的初始化是**线程安全**的（C++11 起由编译器保证），但之后的自增等操作仍需自己加锁。
