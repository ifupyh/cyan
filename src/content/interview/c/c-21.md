## 参考答案

**结论：** 都分配堆内存，区别在**是否初始化**和**参数形式**。

- `malloc(size)`：分配 size 字节，**内容未初始化**（残留脏值）。
- `calloc(n, size)`：分配 n×size 字节，**全部初始化为 0**。

**纠正原稿：** 两者**分配失败都返回 NULL**，calloc 不会抛异常。都要检查返回值：

```c
int *p = malloc(n * sizeof(int));
if (!p) { /* 处理失败 */ }
```

**加分点：** calloc 传两个参数还能在 n×size 溢出时由实现检测，比 `malloc(n*size)` 更安全。
