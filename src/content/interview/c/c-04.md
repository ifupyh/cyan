## 参考答案

**结论：** const 声明的是「只读」变量，表示该对象经程序代码不可被修改。

- 值不可修改：一旦初始化，不能通过该名字再赋值。
- 有作用域：遵循普通变量的作用域规则。
- **注意（纠正原稿）：const 变量并不一定是「编译期常量」**。只有用字面量/常量表达式初始化的才可在编译期确定；`const int x = rand();` 是运行期才确定的。真正要求编译期常量请用 C++ 的 `constexpr`。

```c
const int PI = 3;                 // 编译期可知
const char GREETING[] = "Hello";  // 数组内容不可改
const int r = rand();             // 运行期初始化，仍然只读
```

**加分点：** 在 C++ 中，文件作用域的 `const` 变量默认具有**内部链接**（相当于 static），每个编译单元各有一份；C 语言中 const 仍是外部链接。
