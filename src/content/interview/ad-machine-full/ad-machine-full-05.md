## 参考答案

- 客户把素材给运营商 → 运营商在后台**上传广告、配置播放规则** → 下发 → 后端生成**播放列表（含素材下载 URL）** → 通过 **MQTT 推给设备** → 设备**下载素材到本地** → 存 sqlite → 播放。
- 一句话：**广告资源是后端通过 MQTT 下发 URL，设备再按 URL 下载到本地的**。
- 常见误区（考官点名）：说成"后端通过 ini 配置文件下发"，是错的——ini 只存设备自身配置，不下发广告。
