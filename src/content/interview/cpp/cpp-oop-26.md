## 参考答案

**结论：** 含**纯虚函数**的类是抽象类，不能实例化，用于定义接口。

```cpp
class Shape {
public:
    virtual double area() const = 0;   // 纯虚函数
};
```

特点：
1. 含至少一个纯虚函数。
2. 不能创建对象，只能作基类被继承。
3. 派生类必须实现所有纯虚函数，否则仍是抽象类。
4. 通过基类指针/引用可调用派生类实现，体现多态。
5. 纯虚函数也可以有实现（派生类可显式调用 `Base::f()`）。
